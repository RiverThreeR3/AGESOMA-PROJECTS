# AGESOMA — Public Projects

**Public-facing portfolio of AGESOMA's AI engineering work.**

This repository is exclusively for **public, shareable project showcases**: working demos, open-source releases (where licenses allow), case studies and reproducible technical evidence. It is **not** the internal project-management workspace or the company's shared AI infrastructure repository.

> **Status:** Public portfolio foundation. No product launch, deployment, customer result or performance benchmark is claimed by this README.

## What belongs here

- Public project summaries describing the problem, solution and technical approach.
- Links to existing public product repositories and verified live demos.
- Reproducible technical examples, approved screenshots and clearly labeled sample data.
- Published benchmarks with datasets, environment and limitations.
- Public case studies with explicit permission to share.

## What stays private

- Customer or employee data, real conversations, secrets, tokens, API keys and connection strings.
- Proprietary agent workflows, private prompts, trade secrets and commercial source code.
- Internal plans, revenue targets, lead pipelines, unreleased features and marketing tests.
- Financial or trading systems, account details and production operational controls.

## Publishing criteria

1. The project has a shareable name, scope and permission to publish.
2. The description clearly distinguishes implemented functionality from planned work.
3. Any demo link and performance claim has been tested and is current.
4. Screenshots and media show real product behavior or are clearly labeled as mockups.
5. The entry reveals no credentials, customer data or confidential infrastructure.
6. Attribution and third-party licenses have been reviewed.

**Maintained by AGESOMA.** All public statements should be evidence-based and checked before publication.
